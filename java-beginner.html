    Module 1

    JDK setup and your first program

    Understand JDK, JRE and JVM, install Java, then compile and run Hello World.

    About 45 minutes

    Java is a compiled, object-oriented language. You write source code in .java files, the compiler javac turns it into bytecode (.class files), and the JVM runs that bytecode. Because the JVM exists for Windows, macOS and Linux, the same compiled program runs everywhere. This idea is called "write once, run anywhere".

    PieceWhat it isWho needs it
    JVMRuns bytecode on your machineEveryone, it is inside the JDK
    JREJVM plus core librariesOnly to run programs
    JDKJRE plus javac and toolsYou, since you write code

    Install and verify

    Install a current LTS JDK (17 or 21) from adoptium.net or oracle.com. Open a terminal and check both the runner and the compiler.

    PATH and JAVA_HOME
    javac is not recognized means PATH is wrong. On Windows add the JDK bin folder to PATH and set JAVA_HOME to the JDK folder, then open a NEW terminal.

    Your first program

    Why the long main line
    public = visible to the JVM, static = runs without creating an object, void = returns nothing, String[] args = command-line words. For now, memorise it as the doorway into your program.
    File name must match
    A public class Hello must live in Hello.java, with the same capital letters. Mismatch gives a compile error.

    Key takeaways

    • Source .java -> javac -> bytecode .class -> JVM runs it
    • Install the JDK, not only the JRE
    • main is the entry point; statements end with ;
    • Class name and file name must match

    Practice

    Write Me.java that prints your name on one line and your city on the next.

    Use two System.out.println calls inside main. Class name must be Me.

    Quick quiz

    Which tool turns Hello.java into bytecode?

    javac compiles; java launches the JVM to run the result.

    Module 2

    Variables, data types and input

    Store data with the right type, convert between types, and read keyboard input.

    About 60 minutes

    Java is statically typed: every variable has a type fixed at declaration. A variable is a named box; the type decides what fits inside.

    TypeHoldsExample
    intWhole numbers (about +-2 billion)int age = 21;
    longBigger whole numberslong pop = 1400000000L;
    doubleDecimalsdouble price = 19.99;
    booleantrue or falseboolean ok = true;
    charOne character, single quoteschar grade = 'A';
    StringText, double quotes (a class, not primitive)String name = "Ravi";
    Integer division trap
    7 / 2 is 3, not 3.5. Make one side a double (7 / 2.0) when you need decimals.

    Reading input

    Use var carefully
    var x = 5; lets Java infer the type (still static). Handy for long types; keep explicit types while learning.

    Key takeaways

    • Types are fixed at declaration; pick the smallest fitting one
    • Widening is automatic; narrowing needs a cast
    • int / int stays an int
    • Scanner reads input: nextLine for text, nextInt for numbers

    Practice

    Read two numbers and print their average as a decimal.

    Read with nextDouble, or divide by 2.0.

    Quick quiz

    What does System.out.println(10 / 4); print?

    Both operands are int, so the result is the int 2.

    Module 3

    Decisions and loops

    Make programs choose with if and switch, and repeat work with for, while and do-while.

    About 60 minutes

    Conditions use booleans. Comparisons are == != < > <= >=; combine them with && (and), || (or), ! (not). Never compare Strings with ==; use .equals().

    Missing break and infinite loops
    Without break, switch runs into the next case. A loop whose condition never becomes false never ends; press Ctrl+C to stop it.
    Pick the right loop
    for when you know the count, while when you repeat until something changes, do-while when it must run at least once. break exits a loop; continue skips to the next round.

    Key takeaways

    • if / else if / else picks one branch
    • Strings are compared with .equals()
    • switch needs break per case
    • for = counted, while = condition, do-while = at least once

    Practice

    Print the multiplication table of 5 from 1 to 10.

    A for loop with i from 1 to 10 and print 5 * i.

    Quick quiz

    Which compares two Strings correctly?

    == compares references; .equals() compares the text.

    Module 4

    Methods and arrays

    Package logic into reusable methods and store many values in an array.

    About 60 minutes

    A method is a named block of code with parameters and a return type. An array is a fixed-size, zero-indexed list of one type.

    ArrayIndexOutOfBoundsException
    An array of 3 items has indexes 0, 1, 2. Asking for marks[3] crashes. Array size is fixed; use ArrayList (module 6) for growing lists.
    Overloading
    Two methods may share a name if their parameters differ: add(int, int) and add(double, double). Java picks the match.

    Key takeaways

    • Method = return type + name + parameters
    • Arrays are zero-indexed with fixed size
    • for-each loops read every element
    • Overloading reuses a name with different parameters

    Practice

    Write a method max(int[] a) that returns the largest value.

    Start with best = a[0], then update inside a loop.

    Quick quiz

    Valid indexes for int[] a = new int[5]; are:

    Zero-based: 0,1,2,3,4.

    Module 5

    Classes and objects

    Model real things with fields, constructors, methods and encapsulation.

    About 75 minutes

    A class is a blueprint; an object is one thing built from it with new. Fields hold data, methods hold behaviour, and the constructor sets up a new object. Mark fields private and expose them through methods: this is encapsulation.

    Why encapsulation matters
    If balance were public, any code could set it to -999. Private fields plus checked methods keep the object always valid.
    NullPointerException
    A variable that holds null has no object. Calling a.deposit(5) on it crashes. Always create the object with new first.

    Key takeaways

    • Class = blueprint, object = instance made with new
    • Constructor has the class name and no return type
    • this means the current object
    • Private fields + public methods = encapsulation

    Practice

    Create Student with name and marks, a constructor, and a method isPass() that returns true when marks >= 40.

    Return marks >= 40 directly, it is already a boolean.

    Quick quiz

    What does this.balance = balance; do?

    Left side is the field of the current object, right side is the constructor parameter.

    Module 6

    Collections and exceptions

    Use ArrayList and HashMap, and handle errors with try and catch.

    About 75 minutes

    ArrayList is a resizable list; HashMap stores key-value pairs. Angle brackets name the element type (generics) so the compiler catches wrong types.

    Do not swallow errors
    An empty catch hides bugs. At least print e.getMessage() or rethrow. Catch specific exceptions rather than the broad Exception.
    You finished the basics
    Next level: inheritance, interfaces, streams, files, JUnit and Maven. Build a console To-Do or Bank app with these six modules first.

    Key takeaways

    • ArrayList grows; arrays do not
    • HashMap gives fast lookup by key
    • try / catch / finally handles runtime errors
    • Use generics: List<String>, Map<String, Integer>

    Practice

    Store 3 names in an ArrayList and print each using a for-each loop.

    for (String n : items) then print n.

    Quick quiz

    Which always runs, error or not?

    finally executes in both cases, ideal for cleanup.

    EXAM READINESS EXTENSION · BEGINNER

    The extra fundamentals Java exams expect

    The six core lessons give you a strong start. Exams also test exact language rules, tracing output, short programs, and explanations of why code behaves a certain way. Use this extension as a revision sheet; examples use standard Java syntax and can be adapted to your syllabus.

    Definition bank: Core Java definitions

    Learn these concise definitions for theory questions. In written exams, define the term first, then add a short example when asked.

    Java
    A high-level, class-based programming language designed to run on different platforms through the Java Virtual Machine (JVM).
    JDK (Java Development Kit)
    The tools used to develop Java programs, including the compiler and runtime tools.
    JRE (Java Runtime Environment)
    The runtime components needed to run Java applications; in modern Java distributions, it is commonly delivered as part of a JDK or runtime image.
    JVM (Java Virtual Machine)
    The virtual machine that executes Java bytecode and manages runtime services such as memory.
    Source code
    Human-readable program text written in a language such as Java and saved in a .java file.
    Bytecode
    Platform-independent instructions produced by the Java compiler and usually stored in .class files.
    Compiler
    A program that translates Java source code into bytecode; the Java compiler command is javac.
    Variable
    A named storage location used to hold a value of a declared type.
    Data type
    A classification that determines which values a variable can hold and which operations are valid.
    Primitive type
    One of Java’s eight built-in value types: byte, short, int, long, float, double, char and boolean.
    Reference type
    A type whose variables refer to objects or arrays rather than directly holding a primitive value.
    Operator
    A symbol or keyword that performs an operation, such as +, ==, && or =.
    Conditional statement
    A statement such as if/else or switch that chooses which code runs based on a condition.
    Loop
    A control structure that repeats code, such as for, while or do-while.
    Method
    A named block of code that can accept parameters and may return a result.
    Parameter and argument
    A parameter is a variable in a method declaration; an argument is the actual value supplied when calling it.
    Array
    A fixed-length object that stores multiple values of one declared element type, accessed by zero-based index.
    Class
    A blueprint that declares the fields, constructors and methods associated with a kind of object.
    Object
    A runtime instance of a class, with state represented by fields and behavior represented by methods.
    Constructor
    A special class member used to initialize a new object; it has the class name and no return type.
    Encapsulation
    The practice of keeping an object’s internal state controlled and exposing suitable operations through methods.
    Collection
    An object or framework abstraction for grouping and working with multiple elements, such as a List or Set.
    Exception
    An object representing an event that interrupts the normal flow of program execution.
    Recursion
    A technique in which a method calls itself, normally with a base case that stops further calls.
    Algorithm complexity
    A description of how an algorithm’s time or memory requirements grow as input size increases, often using Big-O notation.

    1. Operators and expression tracing

    Know arithmetic (+ - * / %), comparisons, logical operators, assignment operators and increment/decrement. Integer division discards the fractional part; operator precedence determines grouping.

    int a = 7 / 2;       // 3
int b = 7 % 2;       // 1
int x = 4;
int y = x++ + ++x;   // 4 + 6 = 10; x is 6

    Exam habit: trace each statement in order. Parentheses make intent clearer; avoid complicated expressions with multiple side effects in production code.

    2. Strings

    String objects are immutable: a method such as toUpperCase() returns a string; it does not change the original object. Use equals for text equality, not ==.

    String a = "java";
String b = a.toUpperCase();
System.out.println(a);          // java
System.out.println(b);          // JAVA
System.out.println("java".equals(a)); // true

    Learn length(), charAt(), substring(), contains(), indexOf(), split(), trim()/strip(), and StringBuilder for repeated modifications.

    3. Scope, defaults and casting

    Local variables must be assigned before use. Instance fields receive default values (numeric zero, false, or null for references). Narrowing conversions can lose information.

    double price = 9.8;
int whole = (int) price; // 9
int n = 5;
double d = n;            // 5.0, widening

    Distinguish local variables, parameters, instance fields and static class fields. A variable declared inside a block is not accessible outside that block.

    4. Constructors and access

    A constructor initializes an object and has the same name as its class, with no return type. If you declare no constructor, Java supplies a no-argument default constructor; once you declare one, that automatic constructor is not supplied.

    class Student {
    private String name;
    Student(String name) {
        this.name = name;
    }
    String getName() { return name; }
}

    private restricts access to the class; package-private has no modifier; protected and public have broader access rules. Prefer private fields and controlled methods.

    5. Packages, imports and static

    A package organizes related types and helps define access boundaries. The package declaration, when present, comes before imports. import lets you refer to a type by its simple name. static members belong to the class rather than an individual object.

    import java.util.Scanner;

class Counter {
    static int total = 0;
    Counter() { total++; }
}

    final on a variable means it can be assigned only once; on a method it prevents overriding; on a class it prevents subclassing.

    6. Recursion and algorithm basics

    Recursion is a method calling itself. Every recursive solution needs a base case and progress toward that case. A loop is often simpler for basic repetition.

    static int factorial(int n) {
    if (n < 0) throw new IllegalArgumentException();
    if (n <= 1) return 1; // base case
    return n * factorial(n - 1);
}

    Common complexity vocabulary: O(1) constant, O(n) linear, O(n²) quadratic. A loop inside a loop over the same input is often quadratic.

    Quick reference: common exam distinctions

    ConceptsDifference to state clearly
    == vs equals()For primitives, == compares values. For references, it tests whether references identify the same object. equals() checks logical equality when the class implements it.
    while vs do-whilewhile checks before its body and may run zero times. do-while checks after its body and runs at least once.
    Array vs ArrayListAn array has a fixed length and can store primitives directly. ArrayList grows dynamically and stores objects (use wrapper types such as Integer).
    Overloading vs overridingOverloading uses the same method name with different parameter lists. Overriding replaces inherited instance-method behaviour with a compatible implementation.
    throw vs throwsthrow actually throws an exception object; throws declares possible exceptions in a method signature.
    Compile-time vs runtime errorCompile-time errors prevent compilation (for example, a type mismatch). Runtime exceptions occur while executing (for example, indexing beyond an array).

    Exam-style questions with worked answers

    Q1. What is printed by System.out.println(5 + 2 * 3);?

    Answer: 11. Multiplication has higher precedence than addition: 5 + (2 * 3).

    Q2. Write a method that returns the number of even values in an integer array.

    Answer:

    static int countEven(int[] values) {
    int count = 0;
    for (int value : values) {
        if (value % 2 == 0) count++;
    }
    return count;
}

    This takes O(n) time because each element is checked once. State how you want to handle a null array if the question asks about invalid input.

    Q3. Why can String s = null; s.length(); fail?

    Answer: s refers to no object. Calling an instance method through it throws NullPointerException. Check for null before dereferencing when null is a valid possibility.

    Q4. What is the difference between a class and an object?

    Answer: A class defines a type, its state and behaviour. An object is a runtime instance of that class with its own instance state.

    Q5. What is the output and why?
    int[] a = {2, 4, 6};
System.out.println(a.length);
System.out.println(a[0]);

    Answer: 3, then 2. Length is the number of elements; indexes start at zero.

    Practice checklist

    • Can you write a complete class with main without copying?
    • Can you trace nested loops and predict exact output?
    • Can you write methods for max/min, palindrome, factorial, prime checking and array reversal?
    • Can you explain constructors, encapsulation, inheritance, interfaces and polymorphism in your own words?
    • Can you choose an array, List, Set or Map for a simple problem?
    • Can you identify compile errors, exceptions, off-by-one errors and integer division?
    Exam strategy: Follow the syllabus and Java version named by your institution. For output questions, make a variable trace table; for programming questions, write the method signature first, test normal and boundary cases, then explain complexity if requested.
